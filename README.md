# A minimal personal website

## Structure

- `index.html` - Main HTML file
- `style.css` - All styles
- `minimal.css` - Styles for the main website
- `hairline-loading.css` - Shared loading screen and small creator credit styles
- `script.js` - All JavaScript functionality
- `hairline-loader.js` - Random Hairline loading illustration for the homepage and 404 page
- `404.html` - Custom 404 page

## Deployment [Free of cost]

This website is designed to be deployed on Azure Static Web Apps.

## Local Development

To run locally:

```
npx http-server .
```

## Built With

- HTML5
- CSS3
- JavaScript
- [Hairline](https://github.com/lucasmarkes/hairline) by Lucas Markes - randomly selected loading illustration, displayed for four seconds
